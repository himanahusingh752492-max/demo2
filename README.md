# 🛒 demo2 - E-commerce Website

demo2 is a fully functional e-commerce web application built using Node.js, Express.js, MongoDB, and JavaScript.  
It includes user authentication, middleware-based route protection, connected pages, and database integration.

---

## 🚀 Features

- 🔐 User Signup & Login Authentication
- 🛡 Middleware-based Route Protection
- 🗂 Connected Dynamic Pages
- 🛍 Product Listing
- 🛒 Add to Cart Functionality
- 🗄 MongoDB Database Integration
- 📦 Backend with Express.js
- 🎨 Frontend using HTML, CSS, JavaScript

---

## 🛠 Tech Stack

**Frontend:**
- HTML
- CSS
- JavaScript

**Backend:**
- Node.js
- Express.js

**Database:**
- MongoDB
